# Batam Uncle Says

A mobile-first guide for Singaporeans on a Batam day trip: a day plan built around your ferry times, a fair-price check, money converter, ferry comparison, entry checklist, places, what's on in Batam (events re-read every morning), and show-the-driver phrase cards in Indonesian. English and Chinese. Works offline after the first visit.

Live: https://juw12.github.io/batam-uncle-says/

## Get it on your device

- **Windows:** [`BatamUncleSays-Windows-Setup.exe`](https://github.com/juw12/batam-uncle-says/releases/download/desktop/BatamUncleSays-Windows-Setup.exe) (no admin needed; if Windows says it protected your PC, choose *More info → Run anyway*), or without installing [`BatamUncleSays-Windows-Portable.zip`](https://github.com/juw12/batam-uncle-says/releases/download/desktop/BatamUncleSays-Windows-Portable.zip).
- **Mac:** [`BatamUncleSays-macOS-AppleSilicon.dmg`](https://github.com/juw12/batam-uncle-says/releases/download/desktop/BatamUncleSays-macOS-AppleSilicon.dmg) (M1 and newer) or [`BatamUncleSays-macOS-Intel.dmg`](https://github.com/juw12/batam-uncle-says/releases/download/desktop/BatamUncleSays-macOS-Intel.dmg). The first time, macOS blocks it because it is not notarized: **System Settings → Privacy & Security → Open Anyway**.
- **Android:** [`BatamUncleSays-android.apk`](https://github.com/juw12/batam-uncle-says/releases/download/android/BatamUncleSays-android.apk): open the file on the phone and allow your browser to install apps once.
- **iPhone:** open https://juw12.github.io/batam-uncle-says/ in Safari, tap Share, then **Add to Home Screen**.

The Windows, Mac and Android apps are the web app in its own window ([`desktop/`](desktop/README.md), [`android/`](android/README.md)) and change with it. Each build is opened on GitHub's machines before it is published: on Windows and on a Mac the page loads, the app starts and can store data; on an Android emulator it installs, opens and stays up. They are not code-signed or notarised, and no real phone or PC has run them yet.
